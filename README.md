
# Calculaturation

A simple calculator made with Python and Rich.

## Features
- Pythagorean theorem
- Addition
- Subtraction
- Division
- Multiplication

## Requirements
- Python 3.13+
- Rich

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```
